## Bug 排查 2：insert 报 Field 'id' doesn't have a default value（已定位）

- 用户自己写了 Insert 测试（狂神教程同款），实体加了 `@TableId(type = IdType.AUTO)`，yml 也简化了（去掉了 global-config/type-aliases-package）。
- 报错：`DataIntegrityViolationException` ← `java.sql.SQLException: Field 'id' doesn't have a default value`，生成的 SQL 为 `INSERT INTO user (name, age, email) VALUES (?, ?, ?)`（无 id 列）。
- 用 pymysql `SHOW CREATE TABLE` 验证：user 表 id 列 bigint NOT NULL + PRIMARY KEY，但**没有 AUTO_INCREMENT**（EXTRA 为空）。
- 根因：`IdType.AUTO` 让 MP 省略 id 等数据库自增；但表没声明自增，MySQL 不知道 id 填啥 → 两边互相等 → 报错。用户建表时漏了 AUTO_INCREMENT。
- 修复方案（交给用户执行）：`ALTER TABLE user MODIFY id BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID';`（id 已是主键，加自增即可，现有 5 条数据不受影响，下一条插入 id=6）
- 备选方案：`IdType.AUTO` 改 `IdType.ASSIGN_ID`（雪花算法，MP 自己生成 19 位 id，不依赖表自增）。
